# pxl moose

Ett retro-plattformsspel i webbläsaren där du styr en pixlig älg genom den svenska skogen.

All grafik ritas med kod på en canvas. Byggt med Vite och JavaScript, utan spelmotor.

## Köra lokalt

```bash
npm install
npm run dev
```

## Bygga

```bash
npm run build
```

## Styrning (kommer)

- Gå: piltangenter eller A och D
- Hoppa: mellanslag eller pil upp
